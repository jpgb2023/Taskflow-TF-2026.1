# ATIVIDADE 05 – CRIAÇÃO DOS PROTÓTIPOS  
## Projeto TaskFlow

## 1. Histórias de Usuário Selecionadas

Para a criação dos protótipos do sistema TaskFlow, foram selecionadas as principais histórias de usuário relacionadas ao funcionamento básico do sistema.

### História 1
Como usuário, eu quero criar uma nova tarefa para organizar minhas atividades diárias.

### História 2
Como usuário, eu quero visualizar minhas tarefas cadastradas para acompanhar minhas pendências.

### História 3
Como usuário, eu quero marcar uma tarefa como concluída para controlar o que já foi finalizado.

### História 4
Como usuário, eu quero excluir tarefas que não preciso mais para manter minha lista organizada.

### História 5
Como usuário, eu quero definir prioridade para minhas tarefas para identificar o que é mais urgente.

---

## 2. Fluxo Principal de Cada História

### Criar Tarefa
O usuário acessa a tela principal do sistema, clica na opção de adicionar tarefa, informa título, descrição, data e prioridade. Em seguida, salva a tarefa, que passa a aparecer na lista principal.

### Visualizar Tarefas
O usuário acessa a tela principal e visualiza todas as tarefas cadastradas, podendo identificar o título, data, status e prioridade de cada uma.

### Marcar Tarefa como Concluída
O usuário seleciona uma tarefa pendente e marca como concluída. O sistema atualiza automaticamente o status da tarefa e a exibe como finalizada.

### Excluir Tarefa
O usuário seleciona uma tarefa cadastrada e escolhe a opção de excluir. O sistema remove a tarefa da lista, mantendo a organização do ambiente.

### Definir Prioridade
Ao criar ou editar uma tarefa, o usuário pode escolher uma prioridade: alta, média ou baixa. Essa prioridade será exibida junto à tarefa para facilitar a organização.

---

## 3. Protótipos das Telas

Foram elaborados protótipos de alta fidelidade das principais telas do sistema TaskFlow, representando o fluxo principal das funcionalidades escolhidas.

As telas prototipadas foram:

- Tela de login;
- Tela de cadastro;
- Tela principal com lista de tarefas;
- Tela de criação de nova tarefa;
- Tela de detalhes da tarefa;
- Tela de tarefas concluídas;
- Tela de calendário com lembretes.

O protótipo apresenta a estrutura visual do sistema, os principais botões, campos de preenchimento, filtros, ícones e organização das informações. A proposta é simular a experiência do usuário antes do desenvolvimento do sistema.

---

## 4. Apresentação e Discussão com a Equipe

Os protótipos foram compartilhados entre os integrantes da equipe para análise e discussão. Durante essa etapa, foram avaliados os seguintes pontos:

- Clareza das telas;
- Facilidade de navegação;
- Organização das informações;
- Relação entre o protótipo e as histórias de usuário;
- Possíveis melhorias na interface.

Após a discussão, a equipe verificou que as telas representam corretamente as principais funcionalidades previstas para o sistema.

---

## 5. Validação do Protótipo

A equipe validou o protótipo com base nas histórias de usuário selecionadas. Foi analisado se cada tela atende ao objetivo proposto e se o fluxo do usuário está claro.

O protótipo atende às seguintes necessidades:

- Permite criar tarefas;
- Permite visualizar tarefas cadastradas;
- Permite marcar tarefas como concluídas;
- Permite excluir tarefas;
- Permite definir prioridade;
- Permite visualizar tarefas em calendário.

Com isso, o protótipo foi considerado adequado para representar a proposta inicial do sistema TaskFlow.
