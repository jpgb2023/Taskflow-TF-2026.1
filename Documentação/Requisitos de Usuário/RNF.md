# 1. Requisitos Não Funcionais

<p align="justify">A <i>Tabela 2</i> a seguir contém os <b>Requisitos Não Funcionais (RNF)</b> elicitados utilizando a técnica de Brainstorm.</p>

| ID | Requisito NF | Categoria/Tipo | Prioridade |
| :--- | :--- | :---: | :---: |
| **RNF01** | **Persistência Local:** O sistema deve salvar os dados no **LocalStorage** ou em um banco **MySQL**, garantindo que as tarefas não sumam ao fechar o navegador/app. | Produto/Segurança | Alta |
| **RNF02** | **Responsividade:** A interface deve ser adaptável para telas de smartphones (mín. 360px) e desktops (até 1920px). | Produto/Usabilidade | Alta |
| **RNF03** | **Tempo de Resposta:** Filtros e buscas devem ser processados localmente em menos de 300ms para garantir fluidez. | Produto/Desempenho | Alta |
| **RNF04** | **Tecnologia:** O sistema deve ser desenvolvido utilizando **React.js** com **Styled Components** (ou Tailwind) para garantir modularidade. | Organizacional | Média |
| **RNF05** | **Acessibilidade:** Os elementos clicáveis (botões de check e delete) devem ter área mínima de 44x44px para facilitar o uso em telas touch. | Produto/Usabilidade | Média |
